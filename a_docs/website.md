# 义齿加工所产品展示网站 — 需求（简化版）

> 面向海外牙医/诊所的**产品展示站**，不卖货、不交易，核心目标：**展示产品能力 + 获取询盘**。

## 一、页面结构（6 页）

| 页面 | 内容 |
|------|------|
| Home 首页 | 定位标语 + 产品入口 + 技术亮点 + 合作流程 |
| About Us | 简介、工厂/实验室图、资质、团队 |
| Products | 产品列表页（具体产品确定后填充，预留分类与详情页结构） |
| Technology | 数字化流程（口扫→设计→切削/3D打印→成品） |
| Contact | 询盘表单 + 邮箱/电话/WhatsApp/地址/展会 |
| News（可选） | 动态/案例，利于 SEO，后期再加 |

## 二、功能范围

**必须有：** 中英双语（中/英切换）· 响应式 · 分类浏览+详情页（产品确定后补）· 询盘表单（姓名/邮箱/国家/产品/留言）· WhatsApp 浮动入口 · SEO 基础（meta）· 资质展示（FDA/CE/ISO）

**先期不做：** 购物车/支付 · 注册登录 · 在线下单 · 口扫文件上传（先走邮件）· 多币种换算 · 博客（后期加）

## 五、技术方向

- 轻量、省钱、快速上线：静态站（HTML/CSS/JS）或 WordPress + Astra/GeneratePress
- 表单：Contact Form 7 / WPForms · 图片：WebP 压缩 · 托管：海外主机（SiteGround / Lightsail）
- 域名：简短 `.com`

## 六、你需要提供的内容

公司简介（中/英）· 工厂/团队照片 · 资质扫描件 · 联系方式 · Logo+品牌色（产品资料待产品确定后补充）

## 七、相对参考站（Shimmer）的改进

大图卡片式布局、加"临床优势"视角、WhatsApp 浮动按钮、首页产品快速入口、优先移动端适配。

---

**MVP 范围：** 6 页（Products 页预留结构） + 中英双语 + 询盘表单 + WhatsApp，2–3 周上线。
